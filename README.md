# Freshwater Fish Species App (W05)

## 📌 รายละเอียดโปรเจกต์
แอปพลิเคชัน Flutter สำหรับแสดงข้อมูลสปีชีส์ปลาและข้อมูลการตกปลา พัฒนาต่อยอดจากงาน W04 โดยเพิ่มความสามารถในการแสดงผลรูปภาพหลายภาพต่อ 1 รายการ (Multi-image Gallery / Slider) ในหน้าจอรายละเอียด

## ✨ ฟีเจอร์หลัก
1. **รายการปลา (Fish List Screen):** แสดงรายการปลาพร้อมรูปภาพตัวอย่างและข้อมูลสรุปเบื้องต้น
2. **หน้ารายละเอียด (Fish Detail Screen):** 
   - แสดงแกลเลอรีรูปภาพแนวนอน (สามารถเลื่อนดูภาพหลายๆ ภาพของปลาแต่ละชนิดได้)
   - ฟังก์ชันกดขยายภาพแบบเต็มจอ (InteractiveViewer)
   - ข้อมูลเชิงลึก เช่น ชื่อวิทยาศาสตร์ ถิ่นที่อยู่ น้ำหนักเฉลี่ย ระดับความยาก และคำอธิบาย
3. **การจัดการ Assets:** โหลดภาพท้องถิ่นจากโฟลเดอร์ `assets/images/` ผ่านระบบกำหนดค่าใน `pubspec.yaml`

## 🛠️ เทคโนโลยีที่ใช้
- **Framework:** Flutter (Dart)
- **UI Components:** Stateless/Stateful Widgets, ListView, Card, Horizontal Slider
